# Descripción para la entrega

## Título

TSAP Agent — La IA entiende. TSAP conecta.

## Descripción corta

TSAP es un agente híbrido que comprende preguntas prácticas de estudiantes, identifica al profesional más adecuado dentro de una red curada y facilita la conversación por WhatsApp. Usa IA cuando hay conexión y mantiene un enrutador local como respaldo. La IA no sustituye la experiencia humana: ayuda a encontrarla.

## Innovación

En lugar de intentar responderlo todo, TSAP reconoce cuándo el valor está en una persona con experiencia específica. La integración con WhatsApp lleva el agente al canal cotidiano de estudiantes y profesionales, mientras que su modo local permite demostrar el flujo aun con conectividad limitada.
