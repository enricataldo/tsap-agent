# Descripción para la entrega

## Título

TSAP Agent — La IA entiende. TSAP conecta.

## Descripción corta

TSAP recibe preguntas prácticas por WhatsApp, identifica al profesional más adecuado dentro de una red curada y facilita la derivación. En el MVP, la coordinación pega el mensaje recibido en el panel; la recepción automática mediante webhook es la siguiente etapa. Usa IA cuando hay conexión y mantiene un enrutador local como respaldo. La IA no sustituye la experiencia humana: ayuda a encontrarla.

## Innovación

En lugar de intentar responderlo todo, TSAP reconoce cuándo el valor está en una persona con experiencia específica. WhatsApp es el canal real de entrada; el panel demuestra el análisis y la selección, mientras que su modo local permite mantener el flujo aun con conectividad limitada.
